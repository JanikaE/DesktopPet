# DesktopPet 设计说明

## 1. 产品定位与当前范围

DesktopPet 是面向 Windows 10/11 x64 的离线桌宠与轻量效率工具。核心目标是用常驻桌面的 2D 宠物作为入口，以尽量少打扰用户的方式提供待办和快捷启动功能。

当前版本采用 C#、.NET 8 和 WPF。桌宠使用透明无边框原生窗口，数据保存在本机，不依赖网络或第三方 API。当前范围不包括番茄钟、天气、翻译、AI 对话、云同步、插件、Live2D、序列帧动画和鼠标穿透。

设计原则：

- 桌宠本体、状态、效率工具、数据访问和系统集成保持分离。
- 优先保证拖动、透明窗口、多显示器和托盘等桌面体验稳定。
- 常用操作集中在宠物旁的悬浮窗，设置窗口只保留配置项。
- 以当前真实实现为准，不为尚未开发的能力预先增加复杂架构。

## 2. 技术方案与开发约定

| 项目 | 决定 |
| --- | --- |
| 目标系统 | Windows 10 / Windows 11，x64 |
| UI 框架 | WPF |
| 运行时 | .NET 8 (`net8.0-windows`) |
| 本地设置 | JSON |
| 业务数据 | SQLite (`Microsoft.Data.Sqlite`) |
| 系统托盘 | Windows Forms `NotifyIcon` |
| 窗口 DPI | Per-Monitor V2 |
| 实例策略 | 单实例运行，重复启动时唤醒已有实例 |

开发期间每次修改后应同步更新本文档，关闭旧的 `DesktopPet` 进程，重新构建并运行 Debug 版本，以便立即验证界面和交互。

## 3. 桌宠窗口与素材

桌宠窗口固定为 **256 × 384 DIP**，高度为宽度的 1.5 倍。窗口无边框、背景透明、不可缩放、不显示任务栏按钮，默认始终置顶。置顶状态可从宠物右键菜单、托盘菜单或设置窗口修改并持久化。

程序保存桌宠的 `Left`、`Top` 和置顶设置。再次启动时恢复上次位置；如果显示器布局变化导致位置越界，则至少保留 72 DIP 的可见区域，便于用户将宠物拖回屏幕。

桌宠不再使用序列帧，每个状态只对应一张 PNG：

| 状态 | 素材 | 使用时机 |
| --- | --- | --- |
| `Idle` | `Assets/Pet/idle.png` | 常态或悬浮窗关闭时 |
| `Click` | `Assets/Pet/click.png` | 悬浮窗打开时 |
| `Dragging` | `Assets/Pet/drag.png` | 正在拖动宠物时 |

三张图片采用相同画布比例、角色尺寸和脚底锚点。画布比例为 2:3，与窗口一致；图片左右多余区域应裁剪，半透明像素按素材处理要求改为全透明。

## 4. 状态与基础交互

```text
Idle --单击--> Click --再次单击--> Idle
Idle/Click --开始拖动--> Dragging
Dragging --结束且悬浮窗打开--> Click
Dragging --结束且悬浮窗关闭--> Idle
```

点击和拖动通过系统最小拖动距离区分。拖动结束不能被误判为点击，否则会造成悬浮窗和图片状态不同步。拖动开始显示 `drag.png`，结束后根据悬浮窗状态恢复 `click.png` 或 `idle.png`。

| 操作 | 行为 |
| --- | --- |
| 左键单击宠物 | 打开或关闭左侧悬浮窗，并切换 `Click` / `Idle` |
| 左键拖动宠物 | 移动宠物；悬浮窗打开时同步移动并保持相对位置 |
| 宠物右键 | 显示“置顶、键盘统计、鼠标统计、设置、退出”；不再提供“播放互动动画” |
| 托盘左键 | 显示或隐藏桌宠 |
| 托盘右键 | 显示/隐藏、置顶、设置、退出 |
| 重复启动应用 | 唤醒并激活已运行实例 |
| 全局组合键（显示 / 隐藏） | 按设置的组合键快捷显示或隐藏桌宠，并同步隐藏或恢复悬浮窗 |
| 全局组合键（键盘统计） | 按设置的组合键打开或关闭键盘统计窗口 |
| 全局组合键（鼠标统计） | 按设置的组合键打开或关闭鼠标统计窗口 |

托盘隐藏是应用级联动操作：若悬浮窗正在显示，隐藏桌宠时必须同时隐藏悬浮窗，再次显示时恢复此前打开的悬浮窗。通过宠物单击主动关闭悬浮窗时，不应记为待恢复状态。

## 5. 悬浮窗与窗口联动

快捷悬浮窗是桌宠的从属窗口，高度始终与桌宠一致，默认位于桌宠左侧并保留 12 DIP 间距。它使用非分层无边框外观，不显示任务栏项，不允许单独拖动或调整尺寸。

悬浮窗打开时拖动宠物，悬浮窗必须同步移动并保持相对偏移。拖动结束后，宠物保持 `Click` 状态；不能回到 `Idle` 后要求用户额外点击两次才能关闭悬浮窗。功能悬浮窗与键盘统计窗口互斥，打开其中一个时自动隐藏另一个。

悬浮窗通过 Tab 分为“待办”“剪切板”和“快捷启动”，只展示可立即使用的功能，不承担配置职责。

## 6. 多显示器与 DPI

进程在程序集模块初始化阶段、任何 WPF 窗口创建前启用 Windows Per-Monitor V2 DPI 感知，桌宠、设置窗口和悬浮窗启用布局取整和设备像素对齐。

在不同分辨率或缩放比例的显示器之间拖动时：

- WPF 按目标显示器的 DPI 重新缩放界面。
- 桌宠监听 `WM_DPICHANGED`。
- DPI 或位置变化后，按照保存的相对偏移重新定位悬浮窗。
- 宠物与悬浮窗不能因各自 DPI 换算逐渐产生位置漂移。
- 启动位置按整个虚拟桌面限制，而不是只按主显示器工作区判断。

## 7. UI 视觉规范

设置窗口、快捷悬浮窗与统计窗口统一使用“日系柔和玻璃风”。效率窗口采用非分层不透明窗口，由系统合成圆角并启用 ClearType；只有桌宠本体保留透明分层窗口：

- 乳白和浅紫的柔和背景。
- 大圆角卡片和系统窗口阴影。
- 低饱和紫色强调、胶囊感 Tab 和轻量描边。
- 设置窗口使用自定义无边框标题栏，可通过标题区域拖动。
- 悬浮窗没有标题栏并保持固定尺寸。

多显示器缩放下优先保证文字清晰、边框完整、卡片不溢出以及窗口相对位置稳定。

## 8. 待办功能

- 待办只在悬浮窗中操作，设置窗口不显示待办。
- 不显示“添加”按钮；在输入框输入非空内容后，按回车或点击窗口内输入框之外的任意区域（含空白、Tab 头和列表）自动添加。
- 每行横向填满列表，删除按钮固定在最右侧；内容超出一行时自动换行显示，不出现横向滚动条。
- 勾选即标记完成；完成项使用灰色文字和删除线。
- 支持取消完成和删除。
- 内容与完成状态保存在 SQLite。

## 9. 剪切板功能

- 不监听或自动收集系统剪切板，避免在用户不知情时保存复制内容。
- 可在多行输入框中手动录入，也可点击“读取”将当前系统剪切板文本填入输入框。
- 输入框失去键盘焦点，或点击窗口内输入框之外的任意区域时，将非空内容保存到 SQLite；保留内容原有换行和空白（回车仍用于换行，不触发保存）。
- 已保存内容按新增时间倒序展示，支持一键复制回系统剪切板和删除。
- 系统剪切板暂时被其他程序占用时给出提示，不导致应用退出。

## 10. 键盘统计

- 应用运行期间使用系统全局键盘钩子统计物理键盘按下次数，只保存按键代码、日期与累计次数，不保存输入文本、组合内容或前台应用信息。
- 采用完整 104 键标准布局显示各键统计结果；长按产生的系统重复按键事件不重复计数，松开后再次按下才新增一次。
- 数据按本地自然日汇总保存到 SQLite，每 10 秒批量落盘，并在应用退出及打开统计窗口前立即刷新。
- 桌宠右键菜单提供“键盘统计”，也可通过设置中的全局组合键打开或关闭。统计窗口固定显示在桌宠左侧，跟随桌宠移动，不支持缩放或单独拖动；显示统计窗口期间桌宠保持 `Click` 状态。
- 默认显示不限时间的累计结果，可切换当天、近一周、近一个月或使用起止日期自定义范围。起止日期由与范围选项同一行的单一日期范围控件呈现，按钮文字反映当前范围；点击按钮弹出单个月历，先点开始日期再点结束日期即可选定区间，并自动切换到“自定义”。日期选择器使用强调色标记存在统计数据的日期。
- 当所选时间范围包含当天时，窗口进入实时模式：每次物理按下都立即累加对应键与合计，并给出强调紫闪烁和轻微缩放的按键响应效果。范围不包含当天时只做静态查询，按键不触发任何反馈。长按产生的重复事件在实时模式中同样不重复计数。
- 键盘统计窗口与待办、剪切板、快捷启动所在的功能悬浮窗同时只显示一个。

## 11. 鼠标统计

- 应用运行期间使用系统全局鼠标钩子（`WH_MOUSE_LL`）统计鼠标移动与点击，忽略注入事件；只保存聚合结果，不保存原始连续坐标、前台应用或窗口信息。
- 移动统计在物理像素坐标下按固定网格（64 像素）分桶累计经过 / 驻留次数，并累加相邻采样点距离得到总里程；采样按固定间隔节流，避免高频移动带来的开销。
- 点击统计按左键、右键、中键和滚轮分别计数，记录到对应网格桶，并单独累计双击次数与滚轮格数。
- 数据按本地自然日汇总保存到 SQLite，每 10 秒批量落盘，并在应用退出及打开统计窗口前立即刷新。
- 桌宠右键菜单提供“鼠标统计”，位于“键盘统计”下方，也可通过设置中的全局组合键打开或关闭。统计窗口与键盘统计、功能悬浮窗同时只显示一个；固定显示在桌宠左侧，高度与桌宠一致，宽度按主视图比例推导，跟随桌宠移动，并随托盘隐藏 / 恢复联动，不支持缩放或单独拖动。显示统计窗口期间桌宠保持 `Click` 状态。
- 时间范围控件与键盘统计一致：默认不限时间，可切换当天、近一周、近一个月或使用起止日期自定义范围；日期选择器使用强调色标记存在统计数据的日期。
- 主视图按整个虚拟桌面比例绘制：移动密度以网格热力图着色，点击位置叠加按按钮配色的圆点（大小随该格次数）；同一网格同时存在多种按钮时只画一个圆点，悬停提示按行列出该格内全部按钮的次数与滚轮格数；并在包含当天时实时绘制最近约 2 秒的渐隐轨迹线、点击处给出闪烁反馈。范围不包含当天时只做静态查询，不响应实时事件。
- 窗口底部显示按钮图例、双击次数与滚轮格数；总里程按 96 DPI 近似换算为米 / 千米。图例条目可点击隐藏或重新显示对应颜色的圆点（隐藏项变淡并加删除线），该显示状态持久化到 `settings.json`；隐藏颜色只影响圆点绘制，命中该颜色的实时点击仍会闪烁。

## 12. 快捷启动界面

两个界面均采用“系统大图标在上、名称在下”的卡片布局，并支持拖动排序。排序结果立即持久化到 SQLite，在设置窗口和悬浮窗之间同步，重启后继续保留。

### 悬浮窗

- 单击卡片立即启动目标。
- 每行固定 3 项，图标为 48 × 48 DIP，卡片高度为 88 DIP。
- 网格从顶部按固定行高紧密排列，不将少量项目拉伸到全部高度。
- 内容未超出时不显示滚动条；超出后显示纵向滚动条，不显示横向滚动条。

### 设置窗口

- 支持选择程序、其他文件或文件夹。
- 自动从路径推导默认名称，也允许填写名称。
- 支持添加、删除和双击启动。
- 每行固定 5 项，图标为 48 × 48 DIP，卡片高度为 112 DIP，以容纳名称和删除按钮。
- 内容超出可用区域后显示纵向滚动条。

## 13. 快捷启动执行规则

普通文件、可执行程序和文件夹通过 Windows Shell 启动，工作目录为目标文件所在目录或目标文件夹本身。

`.bat` 和 `.cmd` 使用专门规则，避免批处理在桌宠目录下运行，从而导致相对路径资源（例如 Minecraft 服务端 JAR）无法找到：

1. 在 `%LocalAppData%/DesktopPet/shortcuts/` 创建或更新目标批处理对应的 `.lnk`。
2. 快捷方式以 `cmd.exe /d /c` 运行原批处理。
3. 工作目录固定为批处理所在目录。
4. 由 Windows Shell 启动该快捷方式。
5. 快捷方式名使用目标完整路径的 SHA-256 摘要前缀，避免同名文件冲突。

快捷项的名称、目标路径和排序位置保存在 SQLite。旧数据库启动时自动增加 `sort_order` 字段，并用原记录顺序初始化排序值。

## 14. 设置窗口

设置窗口以多个 Tab 集中配置：

- “常规”：配置桌宠是否始终置顶，以及三组全局组合键——显示 / 隐藏桌宠、打开 / 关闭键盘统计、打开 / 关闭鼠标统计。每组均可单独捕获与清除，未设置时显示“未设置”。
- “快捷启动”：管理快捷项。

待办已从设置窗口移除，所有待办操作均集中在悬浮窗。早期独立的“待办与快捷启动”窗口也已废弃，不应重新引入。

## 15. 数据与文件位置

运行数据统一位于 `%LocalAppData%/DesktopPet/`：

```text
settings.json       # 桌宠位置、置顶偏好、全局组合键与统计窗口显示偏好
desktop-pet.db      # 待办、快捷启动项及排序、键盘与鼠标统计
shortcuts/          # 自动生成的批处理快捷方式
assets/pet/         # 预留本地宠物素材目录
logs/               # 预留日志目录
```

仓库素材位于 `src/DesktopPet/Assets/`。`Assets/icon.ico` 同时作为 EXE 和托盘图标，由用户提供的 `icon.png` 缩放生成多尺寸 ICO。宠物 PNG 在构建时复制到输出目录。

## 16. Windows 系统集成

- 命名互斥体保证单实例。
- 第二次启动通过命名事件通知主实例并激活桌宠。
- 每次启动自动创建或更新桌面的 `DesktopPet.lnk`。
- 每次启动在当前用户的 Windows“启动”目录创建或更新同名快捷方式，实现开机自启动。
- 两份快捷方式均指向当前 EXE，以应用目录作为工作目录并使用 EXE 图标。
- 退出时释放托盘图标、命名事件和互斥体。

## 17. 数据一致性与异常处理

- 快捷目标路径具有唯一约束，重复添加时提示用户。
- 启动快捷项前检查目标是否存在，不存在时提示。
- 快捷项增删或排序后通过仓储事件刷新两个窗口。
- 排序使用 SQLite 事务批量更新，避免只保存部分结果。
- JSON 设置损坏时使用默认位置，不阻止启动。
- 状态图片加载失败时回退到常态图片。

## 19. 验收清单

1. 应用成功构建并启动，且只存在一个实例。
2. 单击、拖动和右键互不误触，三张状态图片切换正确。

## 20. 后续扩展边界

后续可评估提醒、便签、番茄钟、更多宠物角色、主题切换或更完整的日志功能。联网、AI、插件和复杂动画应作为独立阶段设计，不应直接耦合进桌宠窗口；新增功能仍遵守“设置负责配置、悬浮窗负责点击即用”的分工。
