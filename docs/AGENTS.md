# DesktopPet 设计说明

## 1. 产品定位与当前范围

DesktopPet 是面向 Windows 10/11 x64 的桌宠与轻量效率工具。核心目标是用常驻桌面的 2D 宠物作为入口，以尽量少打扰用户的方式提供待办和快捷启动功能。

当前版本采用 C#、.NET 8 和 WPF。桌宠使用透明无边框原生窗口，业务数据保存在本机；待办与便签可选依赖本机 OneDrive 客户端，通过同步目录跨设备合并，不调用 Microsoft Graph 或第三方 API。当前范围不包括番茄钟、天气、翻译、AI 对话、插件、Live2D、序列帧动画和鼠标穿透。

设计原则：

- 桌宠本体、状态、效率工具、数据访问和系统集成保持分离。
- 优先保证拖动、透明窗口、多显示器和托盘等桌面体验稳定。
- 常用操作集中在宠物旁的悬浮窗，设置窗口只保留配置项。
- 以当前真实实现为准，不为尚未开发的能力预先增加复杂架构。

## 2. 技术方案与开发约定

| 项目 | 决定 |
| --- | --- |
| 目标系统 | Windows 10 / Windows 11，x64 |
| UI 框架 | WPF |
| 运行时 | .NET 8 (`net8.0-windows`) |
| 本地设置 | JSON |
| 业务数据 | SQLite (`Microsoft.Data.Sqlite`) |
| 待办与便签跨设备同步 | 本机 OneDrive 同步目录、每设备 JSON 副本 |
| 系统托盘 | Windows Forms `NotifyIcon` |
| 窗口 DPI | Per-Monitor V2 |
| 实例策略 | 单实例运行，重复启动时唤醒已有实例 |

开发期间每次修改后应同步更新本文档，关闭旧的 `DesktopPet` 进程，重新构建并运行 Debug 版本，以便立即验证界面和交互。

## 3. 桌宠窗口与素材

桌宠窗口默认为 **256 × 384 DIP**，高度始终为宽度的 1.5 倍。右键菜单中的“缩放大小”会显示缩放边框，拖动任意边或角可等比缩放；点击边框之外或切换到其他窗口时退出缩放模式。窗口无系统边框、背景透明、不显示任务栏按钮，默认始终置顶。尺寸、位置与置顶状态均持久化。

程序保存桌宠的 `Left`、`Top`、`Width` 和置顶设置，并按固定宽高比恢复高度。再次启动时恢复上次位置和尺寸；如果显示器布局变化导致位置越界，则至少保留 72 DIP 的可见区域，便于用户将宠物拖回屏幕。

桌宠不再使用序列帧。内置默认桌宠与每个 PNG 自定义项均按状态对应单张 PNG：

| 状态 | 素材 | 使用时机 |
| --- | --- | --- |
| `Idle` | `Assets/Pet/idle.png` | 常态或悬浮窗关闭时 |
| `Click` | `Assets/Pet/click.png` | 悬浮窗打开时 |
| `Dragging` | `Assets/Pet/drag.png` | 正在拖动宠物时 |

`Idle` 必须存在；`Click` 与 `Dragging` 可选，缺失时回退到 `Idle`。内置默认 PNG 作为不可删除的预设，设置中的“桌宠外观”页可以在默认预设与多个自定义项之间即时切换，也可以添加、编辑或删除自定义项。删除当前项前需要确认，并先切回默认预设。

自定义图片允许任意宽高比，使用 `Uniform` 完整居中显示，不裁剪或拉伸；仍推荐采用与窗口一致的 2:3 画布，并让三张图保持相同角色尺寸和脚底锚点，避免状态切换时跳动。导入时实际解码并验证 PNG，单张最大 20 MB、宽高均不超过 8192 像素。程序复制图片到本地宠物包，不依赖用户原始文件路径。

桌宠窗口承载统一的 `IPetRenderer`，当前由 `PngPetRenderer` 实现。宠物包清单带 `rendererType` 与版本号；未来增加 Live2D 时使用独立渲染器和资源清单，状态机、设置选择与窗口交互不直接依赖 PNG。

## 4. 状态与基础交互

```text
Idle --单击--> Click --再次单击--> Idle
Idle/Click --开始拖动--> Dragging
Dragging --结束且悬浮窗打开--> Click
Dragging --结束且悬浮窗关闭--> Idle
```

点击和拖动通过系统最小拖动距离区分。拖动结束不能被误判为点击，否则会造成悬浮窗和图片状态不同步。拖动开始显示 `drag.png`，结束后根据悬浮窗状态恢复 `click.png` 或 `idle.png`。

| 操作 | 行为 |
| --- | --- |
| 左键单击宠物 | 打开或关闭左侧悬浮窗，并切换 `Click` / `Idle` |
| 左键拖动宠物 | 移动宠物；悬浮窗打开时同步移动并保持相对位置 |
| 宠物右键 | 显示“置顶、键盘统计、鼠标统计、设置、退出”；不再提供“播放互动动画” |
| 托盘左键 | 显示或隐藏桌宠 |
| 托盘右键 | 显示/隐藏、置顶、设置、退出 |
| 重复启动应用 | 唤醒并激活已运行实例 |
| 全局组合键（显示 / 隐藏） | 按设置的组合键快捷显示或隐藏桌宠，并同步隐藏或恢复悬浮窗 |
| 全局组合键（键盘统计） | 按设置的组合键打开或关闭键盘统计窗口 |
| 全局组合键（鼠标统计） | 按设置的组合键打开或关闭鼠标统计窗口 |

托盘隐藏是应用级联动操作：若悬浮窗正在显示，隐藏桌宠时必须同时隐藏悬浮窗，再次显示时恢复此前打开的悬浮窗。通过宠物单击主动关闭悬浮窗时，不应记为待恢复状态。

## 5. 悬浮窗与窗口联动

快捷悬浮窗是桌宠的从属窗口，高度固定为 384 DIP，默认位于桌宠左侧并保留 12 DIP 间距，窗口下沿与桌宠下沿对齐。它使用非分层无边框外观，不显示任务栏项，不允许单独拖动或调整尺寸；桌宠缩放不改变悬浮窗尺寸。

悬浮窗打开时拖动宠物，悬浮窗必须同步移动并保持相对偏移。拖动结束后，宠物保持 `Click` 状态；不能回到 `Idle` 后要求用户额外点击两次才能关闭悬浮窗。功能悬浮窗与键盘统计窗口互斥，打开其中一个时自动隐藏另一个。

悬浮窗通过 Tab 分为“待办”“剪切板”“便签”和“快捷启动”，只展示可立即使用的功能，不承担配置职责。

## 6. 多显示器与 DPI

进程在程序集模块初始化阶段、任何 WPF 窗口创建前启用 Windows Per-Monitor V2 DPI 感知，桌宠、设置窗口和悬浮窗启用布局取整和设备像素对齐。

在不同分辨率或缩放比例的显示器之间拖动时：

- WPF 按目标显示器的 DPI 重新缩放界面。
- 桌宠监听 `WM_DPICHANGED`。
- DPI 或位置变化后，按照保存的相对偏移重新定位悬浮窗。
- 宠物与悬浮窗不能因各自 DPI 换算逐渐产生位置漂移。
- 启动位置按整个虚拟桌面限制，而不是只按主显示器工作区判断。

## 7. UI 视觉规范

设置窗口、快捷悬浮窗与统计窗口统一使用“日系柔和玻璃风”。效率窗口采用非分层不透明窗口，由系统合成圆角并启用 ClearType；只有桌宠本体保留透明分层窗口：

- 乳白和浅紫的柔和背景。
- 大圆角卡片和系统窗口阴影。
- 低饱和紫色强调、胶囊感 Tab 和轻量描边。
- 设置窗口使用自定义无边框标题栏，可通过标题区域拖动。
- 悬浮窗没有标题栏并保持固定尺寸。

多显示器缩放下优先保证文字清晰、边框完整、卡片不溢出以及窗口相对位置稳定。

## 8. 待办功能

- 待办只在悬浮窗中操作，设置窗口不显示待办。
- 不显示“添加”按钮；在输入框输入非空内容后，按回车或点击窗口内输入框之外的任意区域（含空白、Tab 头和列表）自动添加。
- 每行横向填满列表，删除按钮固定在最右侧；内容超出一行时自动换行显示，不出现横向滚动条。
- 勾选即标记完成；完成项使用灰色文字和删除线。
- 支持取消完成和删除。
- 内容与完成状态保存在 SQLite。
- 可在设置中启用 OneDrive 文件夹同步；本地操作始终立即写入 SQLite，不等待 OneDrive 上传。
- 每条待办使用跨设备 GUID，新增、完成状态变化与删除均记录为幂等操作；删除使用永久墓碑，避免离线设备重新带回已删除项目。
- 多台设备分别写入自己的副本文件并读取所有副本，不共同覆盖同一个 JSON；合并使用逻辑时钟和设备 ID 稳定处理并发，删除优先，同标题项目不自动去重。

### OneDrive 数据同步

- 不使用 Microsoft Entra、Microsoft Graph、OAuth 或访问令牌，完全依赖用户已经安装并登录的 OneDrive Windows 客户端。
- 默认通过 Windows `FOLDERID_SkyDrive` 查找主要 OneDrive 目录，并使用 `Apps/DesktopPet/` 作为同步根目录；未找到、多账号或企业目录场景允许用户手动选择同步根目录。
- 待办副本位于根目录的 `TodoSync/replicas/`，便签副本位于同级的 `NoteSync/replicas/`。每台设备以本机生成且不上传到其他设置位置的设备 GUID 命名自己的 JSON。
- 写副本时先写 `.partial` 临时文件，再原子替换正式 JSON。应用忽略临时文件，只扫描 `*.json`；OneDrive 产生的冲突副本也会被扫描，操作按全局 GUID 去重。
- `FileSystemWatcher` 发现变更后延迟 1 秒合并；本地待办变化延迟 2 秒导出；每 60 秒完整扫描一次，补偿文件监听丢失、Files On-Demand 下载和同步延迟。
- SQLite 是即时数据源。同步目录不可用、OneDrive 暂停或离线时仍可增删改待办与便签，目录恢复后自动导出和合并。
- 应用只能确认文件已写入本地 OneDrive 目录，不能确认 OneDrive 客户端已完成云端上传；界面不得显示“云端同步完成”，实际上传状态以 OneDrive 托盘客户端为准。
- 无效、损坏、超过大小限制（待办 16 MB、便签 32 MB）、记录数超过 100,000 或高于当前架构版本的副本会被忽略并显示警告，不覆盖来源文件，也不阻止其他有效副本合并。

## 9. 剪切板功能

- 不监听或自动收集系统剪切板，避免在用户不知情时保存复制内容。
- 可在多行输入框中手动录入，也可点击“读取”将当前系统剪切板文本填入输入框。
- 输入框失去键盘焦点，或点击窗口内输入框之外的任意区域时，将非空内容保存到 SQLite；保留内容原有换行和空白（回车仍用于换行，不触发保存）。
- 已保存内容按新增时间倒序展示，支持一键复制回系统剪切板和删除。
- 系统剪切板暂时被其他程序占用时给出提示，不导致应用退出。

## 10. 便签功能

- 便签只在悬浮窗中操作，不创建独立桌面窗口。列表使用统一的柔和玻璃风卡片，按最后修改时间倒序排列。
- 点击“新建便签”后在当前 Tab 内切换到编辑视图；点击已有卡片同样进入编辑视图，返回后恢复列表。
- 便签只支持纯文本和换行，不支持标题、颜色、搜索、标签、归档、置顶、手动排序、Markdown、富文本或附件。列表直接显示正文摘要、修改时间和冲突副本标记。
- 停止输入 1 秒后自动写入 SQLite；离开编辑页、隐藏悬浮窗或退出应用时立即补保存。新建空便签不保存，已有便签允许保存为空内容。
- 单条便签最多 `10,000` 个字符，编辑器显示实时字数并在达到上限后阻止继续输入。
- 删除有内容的便签需要二次确认；新建空便签可直接放弃。
- 便签同步使用带版本向量的完整快照。普通前后修改按因果关系覆盖；两台设备离线并发修改同一便签时，确定性选择一个版本作为原便签，并将其他版本生成为带“冲突副本”标记的普通便签。
- 冲突副本 ID 由原便签 ID 和冲突修订 ID 确定性生成，同一冲突不会在重复扫描或不同设备上重复创建。删除与离线编辑并发时保留删除墓碑，并将未见过删除的编辑内容生成为冲突副本。

## 11. 键盘统计

- 应用运行期间使用系统全局键盘钩子统计物理键盘按下次数，只保存按键代码、日期与累计次数，不保存输入文本、组合内容或前台应用信息。
- 支持在 104 键全尺寸与 87 键 ANSI TKL 两种配列间切换；配列只影响键盘热力图的排列与可见键位，不改变底层统计，87 键视图中隐藏的小键盘按键仍计入合计与趋势。所选配列保存到 `settings.json`。长按产生的系统重复按键事件不重复计数，松开后再次按下才新增一次。
- 数据按本地自然日汇总保存到 SQLite，每 10 秒批量落盘，并在应用退出及打开统计窗口前立即刷新。
- 桌宠右键菜单提供“键盘统计”，也可通过设置中的全局组合键打开或关闭。统计窗口固定显示在桌宠左侧，下沿与桌宠下沿对齐，跟随桌宠移动，不支持缩放或单独拖动；显示统计窗口期间桌宠保持 `Click` 状态。
- 默认显示不限时间的累计结果，可切换当天、近一周、近一个月或使用起止日期自定义范围。起止日期由与范围选项同一行的单一日期范围控件呈现，按钮文字反映当前范围；点击按钮弹出单个月历，先点开始日期再点结束日期即可选定区间，并自动切换到“自定义”。日期选择器使用强调色标记存在统计数据的日期。
- 统计窗口可在“按键分布”和“每日趋势”间切换，保持原窗口尺寸与当前时间范围。每日趋势按自然日绘制全部已记录按键的总次数，缺失日期按零处理，悬停显示具体日期和次数；范围包含当天时实时更新当天数据点。
- 趋势图保留每日数据精度，但横轴刻度随跨度自动调整：31 天以内按天、32～180 天按周（周一为刻度基准）、超过 180 天按月；空间不足时在当前粒度内自动跳过部分标签，避免重叠。
- 当所选时间范围包含当天时，窗口进入实时模式：每次物理按下都立即累加对应键与合计，并给出强调紫闪烁和轻微缩放的按键响应效果。范围不包含当天时只做静态查询，按键不触发任何反馈。长按产生的重复事件在实时模式中同样不重复计数。
- 键盘统计窗口与待办、剪切板、快捷启动所在的功能悬浮窗同时只显示一个。

## 12. 鼠标统计

- 应用运行期间使用系统全局鼠标钩子（`WH_MOUSE_LL`）统计鼠标移动与点击，忽略注入事件；只保存聚合结果，不保存原始连续坐标、前台应用或窗口信息。
- 移动统计先判断鼠标所在的显示器，再按该显示器的分辨率归一化为固定 `32 × 18` 网格分桶累计经过 / 驻留次数，因此不同分辨率或缩放比例的显示器上相同相对位置共用一个计数；同时累加相邻采样点的物理像素距离得到总里程。采样按固定间隔节流，避免高频移动带来的开销。
- 点击统计按左键、右键、中键和滚轮分别计数，记录到对应网格桶，并单独累计双击次数与滚轮格数。
- 数据按本地自然日汇总保存到 SQLite，每 10 秒批量落盘，并在应用退出及打开统计窗口前立即刷新。
- 桌宠右键菜单提供“鼠标统计”，位于“键盘统计”下方，也可通过设置中的全局组合键打开或关闭。统计窗口与键盘统计、功能悬浮窗同时只显示一个；固定显示在桌宠左侧，高度固定为 384 DIP，下沿与桌宠下沿对齐，宽度按主视图比例推导，跟随桌宠移动，并随托盘隐藏 / 恢复联动，不支持缩放或单独拖动。显示统计窗口期间桌宠保持 `Click` 状态。
- 时间范围控件与键盘统计一致：默认不限时间，可切换当天、近一周、近一个月或使用起止日期自定义范围；日期选择器使用强调色标记存在统计数据的日期。
- 主视图按参考屏幕（主显示器）比例绘制 `32 × 18` 热力图：移动密度以网格着色，点击位置叠加按按钮配色的圆点（大小随该格次数）；多台显示器上相同相对位置的统计合并到同一格。同一网格同时存在多种按钮时只画一个圆点，悬停提示按行列出该格内全部按钮的次数与滚轮格数；并在包含当天时实时绘制最近约 2 秒的渐隐轨迹线、点击处给出闪烁反馈，实时坐标同样按所在显示器归一化。范围不包含当天时只做静态查询，不响应实时事件。
- 窗口底部显示按钮图例、双击次数与滚轮格数；总里程按 96 DPI 近似换算为米 / 千米。图例条目可点击隐藏或重新显示对应颜色的圆点（隐藏项变淡并加删除线），该显示状态持久化到 `settings.json`；隐藏颜色只影响圆点绘制，命中该颜色的实时点击仍会闪烁。

## 13. 快捷启动界面

两个界面均采用“系统大图标在上、名称在下”的卡片布局，并支持拖动排序。排序结果立即持久化到 SQLite，在设置窗口和悬浮窗之间同步，重启后继续保留。

### 悬浮窗

- 单击卡片立即启动目标。
- 每行固定 3 项，图标为 48 × 48 DIP，卡片高度为 98 DIP。
- 网格从顶部按固定行高紧密排列，不将少量项目拉伸到全部高度。
- 内容未超出时不显示滚动条；超出后显示纵向滚动条，不显示横向滚动条。
- 卡片右下角提供“添加项目”按钮，点击跳转到设置窗口的“快捷启动”页。
- 名称显示占两行高度，单行名称垂直居中；过长时以省略号截断显示；鼠标悬浮卡片显示完整路径提示。
- 悬浮窗只读展示，单击启动；名称编辑仅在设置窗口进行。

### 设置窗口

- 支持选择其他文件或文件夹；顶部仅保留“选择文件夹”和“选择文件”两个按钮。
- 选择后在弹窗中选取即可直接添加到列表，自动从路径推导默认名称（文件夹用文件夹名、文件用不含扩展名的文件名），无需再点击“添加”。
- 删除通过右键卡片菜单选择“删除”，卡片上不显示删除按钮。
- 每行固定 5 项，图标为 48 × 48 DIP，卡片高度为 98 DIP。
- 内容超出可用区域后显示纵向滚动条。
- 名称显示占两行高度，单行名称垂直居中；过长时以省略号截断显示；鼠标悬浮卡片显示完整路径提示。
- 双击卡片进入名称编辑，点击卡片外任意处、回车或失去焦点后保存并持久化；悬浮窗与设置窗通过仓储事件保持同步。

## 14. 快捷启动执行规则

普通文件、可执行程序和文件夹通过 Windows Shell 启动，工作目录为目标文件所在目录或目标文件夹本身。

`.bat` 和 `.cmd` 使用专门规则，避免批处理在桌宠目录下运行，从而导致相对路径资源（例如 Minecraft 服务端 JAR）无法找到：

1. 在 `%LocalAppData%/DesktopPet/shortcuts/` 创建或更新目标批处理对应的 `.lnk`。
2. 快捷方式以 `cmd.exe /d /c` 运行原批处理。
3. 工作目录固定为批处理所在目录。
4. 由 Windows Shell 启动该快捷方式。
5. 快捷方式名使用目标完整路径的 SHA-256 摘要前缀，避免同名文件冲突。

快捷项的名称、目标路径和排序位置保存在 SQLite。旧数据库启动时自动增加 `sort_order` 字段，并用原记录顺序初始化排序值。

## 15. 设置窗口

设置窗口以多个 Tab 集中配置：

- “常规”：配置桌宠是否始终置顶，以及三组全局组合键——显示 / 隐藏桌宠、打开 / 关闭键盘统计、打开 / 关闭鼠标统计。每组均可单独捕获与清除，未设置时显示“未设置”。
- “桌宠外观”：切换内置默认预设或自定义桌宠；管理多个自定义项，并为每项设置必填的 `Idle` PNG 与可选的 `Click`、`Dragging` PNG。新建后自动选中，编辑当前项后立即刷新。
- “快捷启动”：管理快捷项。选择文件或文件夹后立即添加，右键删除、双击编辑名称、拖放排序。
- “OneDrive 同步”：统一启用或停用待办与便签同步、选择同步根目录、立即扫描、打开目录，并显示最近一次本地合并时间和错误状态。根目录内固定使用同级的 `TodoSync` 和 `NoteSync`；停用同步不删除本地或 OneDrive 文件。

待办已从设置窗口移除，所有待办操作均集中在悬浮窗。早期独立的“待办与快捷启动”窗口也已废弃，不应重新引入。

## 16. 数据与文件位置

运行数据统一位于 `%LocalAppData%/DesktopPet/`：

```text
settings.json       # 桌宠位置、置顶偏好、全局组合键与统计窗口显示偏好
desktop-pet.db      # 待办、快捷启动项及排序、键盘与鼠标统计
shortcuts/          # 自动生成的批处理快捷方式
assets/pet/         # 本地宠物素材目录
assets/pet/packages/<guid>/ # 自定义宠物包（manifest.json 与已复制的 PNG）
logs/               # 预留日志目录
```

启用同步后，用户配置的是 `TodoSync` 上一级根目录，默认结构为：

```text
<OneDrive>/Apps/DesktopPet/
├─ TodoSync/replicas/<device-guid>.json
└─ NoteSync/replicas/<device-guid>.json
```

数据库架构版本为 `3`：`todos` 使用稳定 GUID、删除墓碑和幂等操作日志；`notes` 保存正文、冲突标记、删除墓碑、当前修订及版本向量；`sync_metadata` 保存共用的设备 ID、逻辑时钟、启用状态与同步根目录。旧待办首次启动时自动分配 GUID 并生成初始 `add` 操作；原有内容和完成状态保持不变。

旧版配置若指向名称为 `TodoSync` 的标准目录，升级后自动把其上一级记录为同步根目录且不移动副本文件。名称不是 `TodoSync` 的旧版自定义目录不会自动迁移，界面提示用户重新选择根目录，避免程序擅自移动 OneDrive 文件。

鼠标网格统计升级为按显示器归一化的 `32 × 18` 网格后，数据库 `user_version` 会写入 `1`，并在首次升级时清空旧的绝对坐标网格数据（`mouse_heatmap`、`mouse_clicks`），其余数据保留。

仓库素材位于 `src/DesktopPet/Assets/`。`Assets/icon.ico` 同时作为 EXE 和托盘图标，由用户提供的 `icon.png` 缩放生成多尺寸 ICO。内置宠物 PNG 在构建时复制到输出目录。

自定义宠物包位于 `%LocalAppData%/DesktopPet/assets/pet/packages/<guid>/`；每包包含版本化 `manifest.json`、必填 `idle.png` 及可选状态图片。导入与更新先在同级临时目录完整写入并验证，再替换正式目录；无效或损坏的单个包会被目录扫描忽略，当前选择不可用时回退到内置默认预设。`settings.json` 只保存当前宠物 ID，不集中保存宠物包清单。

## 17. Windows 系统集成

- 命名互斥体保证单实例。
- 第二次启动通过命名事件通知主实例并激活桌宠。
- 每次启动自动创建或更新桌面的 `DesktopPet.lnk`。
- 每次启动在当前用户的 Windows“启动”目录创建或更新同名快捷方式，实现开机自启动。
- 两份快捷方式均指向当前 EXE，以应用目录作为工作目录并使用 EXE 图标。
- 退出时释放托盘图标、命名事件和互斥体。

## 18. 数据一致性与异常处理

- 快捷目标路径具有唯一约束，重复添加时提示用户。
- 启动快捷项前检查目标是否存在，不存在时提示。
- 快捷项增删或排序后通过仓储事件刷新两个窗口。
- 排序使用 SQLite 事务批量更新，避免只保存部分结果。
- JSON 设置损坏时使用默认位置，不阻止启动。
- 状态图片加载失败时回退到常态图片。
- 待办同步文件按操作 GUID 幂等导入；并发完成状态按逻辑时钟、设备 ID、操作 ID 依次决胜，任何删除操作均优先于状态修改。
- 便签副本按版本向量判断因果关系；并发正文与删除冲突生成确定性的冲突副本，重复导入不会增加副本数量。
- 同步文件被占用或尚未完成按需下载时短暂重试；持续异常的单个副本被隔离为警告，本地待办和其他有效副本继续工作。

## 20. 验收清单

1. 应用成功构建并启动，且只存在一个实例。
2. 单击、拖动和右键互不误触，三张状态图片切换正确。
3. 悬浮窗开关、宠物状态以及托盘隐藏/恢复保持一致。
4. 拖动宠物时悬浮窗同步移动，跨不同 DPI 显示器后仍保持相对位置。
5. 待办可自动添加、完成、取消完成和删除，显示样式正确。
6. 复制外部内容时不会被自动收集；剪切板页可手动输入或读取系统剪切板，失焦保存，已保存内容可复制和删除。
7. 全局键盘统计按自然日持久化，长按不重复累计；104 键与 87 键配列切换、每日趋势和所有时间范围筛选正确；趋势横轴随跨度切换日 / 周 / 月刻度，范围包含当天时按键实时累加并给出响应效果，不包含当天时不响应。
8. 键盘统计窗口与功能悬浮窗互斥显示，并随桌宠移动和隐藏、恢复。
9. 全局鼠标统计按自然日持久化，热力图与点击标记按鼠标所在显示器归一化到 `32 × 18` 网格，多屏相同相对位置合并计数；范围包含当天时移动实时加深、点击实时闪烁并绘制渐隐轨迹，不包含当天时不响应；所有时间范围筛选正确。
10. 鼠标统计窗口与键盘统计、功能悬浮窗互斥显示，并随桌宠移动和隐藏、恢复。
11. 快捷项在设置页显示 5 列、悬浮窗显示 3 列，行高固定且滚动条按需出现。
12. 两处均可拖动排序，重启后顺序不变。
13. 普通程序、文件夹以及依赖相对路径的 `.bat`/`.cmd` 均从正确工作目录启动。
14. 桌面快捷方式、托盘图标、EXE 图标和开机自启动入口正常。
15. 三组全局组合键（显示 / 隐藏桌宠、打开 / 关闭键盘统计、打开 / 关闭鼠标统计）均可配置、重新设置、清除并持久化；重复按统计快捷键可在打开与关闭之间切换，组合键被占用时给出提示。
16. 便签可新建、自动保存、重新编辑和删除；10,000 字符限制生效，有内容删除时二次确认，空白新便签直接放弃。
17. 未安装或未登录 OneDrive 时不影响本地待办和便签；可手动选择同步根目录并启用、停用或立即扫描。
18. 两台设备分别新增、完成、取消完成和删除待办后能最终合并；并发删除不复活，并发状态修改得到稳定一致结果。
19. 两台设备离线修改同一便签时只生成一个稳定冲突副本；删除与离线编辑并发时正文仍能通过冲突副本找回。
20. OneDrive 产生重名冲突副本、同步目录暂时不可用或单个 JSON 损坏时不丢失本地数据，界面显示准确状态且恢复后可继续同步。
21. 设置中可在默认预设和多个自定义桌宠间即时切换；仅上传 Idle 可以正常使用，缺少的 Click / Dragging 状态回退到 Idle。
22. 自定义桌宠添加、编辑、删除后立即生效并可在重启后恢复；删除当前项会先切回默认预设，损坏或丢失的当前包不会阻止应用启动。

## 21. 后续扩展边界

后续可评估提醒、番茄钟、更多内置预设、Live2D、主题切换或更完整的日志功能。Live2D 通过新增 `IPetRenderer` 实现和对应宠物包清单接入，不改变桌宠状态机与选择存储。直接联网、AI、插件和复杂动画应作为独立阶段设计，不应直接耦合进桌宠窗口；新增功能仍遵守“设置负责配置、悬浮窗负责点击即用”的分工。
